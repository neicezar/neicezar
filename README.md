## 🇧🇷 Português

### Sobre mim

Sou desenvolvedor Java Full Stack com mais de 4 anos de experiência. Trabalho principalmente no back-end, com Spring Boot 3, JPA/Hibernate e microsserviços que conversam por REST e RabbitMQ, e faço o front-end em Angular quando o projeto pede. Hoje estudo System Design e a integração de LLMs em aplicações Java.

### O que já entreguei

- **40% menos tempo de resposta** em aplicações de produção, com a refatoração da camada de persistência e a otimização de queries no SQL Server.
- **Sistema de gestão de frotas e patrimônio em microsserviços** (viaturas, patrimônio e notificações), com comunicação síncrona por REST e assíncrona por RabbitMQ, em contêineres Docker.
- **Serviço de API Composition** que junta dados de viaturas e patrimônio em uma única resposta e reduz as chamadas feitas pelo front-end.
- **Spring Cloud Gateway** como ponto único de entrada, com roteamento, autenticação, autorização e rate limiting por IP.
- **Sincronização com sistema legado** via RabbitMQ, sem travar o sistema principal.
- **APIs RESTful integradas ao AWS S3** para gestão de documentos, com interfaces em Angular 15+.

## 🇺🇸 English

### About me

I'm a Java Full Stack developer with over 4 years of experience. Most of my work is on the back end, with Spring Boot 3, JPA/Hibernate and microservices that talk over REST and RabbitMQ, and I build the front end in Angular when the project calls for it. I'm currently studying System Design and LLM integration in Java applications. Based in Brasília, Brazil, and open to remote work.

### What I've delivered

- **40% lower response times** in production applications, by refactoring the persistence layer and tuning SQL Server queries.
- **Fleet and asset management system built on microservices** (vehicles, assets and notifications), with synchronous REST and asynchronous RabbitMQ communication, running in Docker containers.
- **API Composition service** that merges vehicle and asset data into a single response and cuts the number of calls made by the front end.
- **Spring Cloud Gateway** as the single entry point, handling routing, authentication, authorization and per-IP rate limiting.
- **Legacy system synchronization** through RabbitMQ, without blocking the main system.
- **RESTful APIs integrated with AWS S3** for document management, with Angular 15+ interfaces.
